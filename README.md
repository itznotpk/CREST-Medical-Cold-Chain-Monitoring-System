## Overview

This is an interactive web-based dashboard for monitoring and managing medical cold chain logistics. The system tracks temperature, location, and equipment status for vaccine storage and medical products in real-time.

This is a **frontend prototype** showcasing the dashboard interface with interactive visualization, KPI monitoring, and multi-page navigation.

---

## Key Features

✨ **Real-Time Dashboard**
- Live KPI cards for temperature, equipment status, and compliance metrics
- Multi-page navigation system (Dashboard, Equipment, Reports, Settings)
- Color-coded alerts and status indicators

📊 **Data Visualization**
- Interactive charts using Chart.js
- Temperature trend monitoring
- Equipment performance analytics
- Real-time metrics display

🗺️ **Location Tracking**
- Leaflet map integration for facility locations
- Equipment GPS tracking visualization
- Multi-facility monitoring support

🎨 **Interactive UI**
- Responsive sidebar navigation
- Modern gradient design
- Smooth transitions and animations
- Color-coded status system (Green/Orange/Red)

## How to Use

### 1. Open the Dashboard

Simply open `index.html` in any modern web browser:

```bash
# On Windows
start index.html

# On macOS
open index.html

# On Linux
xdg-open index.html
```

Or drag & drop the file into your browser.

### 2. Navigate Pages

Use the sidebar menu to switch between:
- **Dashboard** - Overview and KPI metrics
- **Equipment** - Individual device monitoring
- **Reports** - Analysis and compliance reports
- **Settings** - Configuration and preferences

### 3. Interactive Elements

- Click cards and buttons to interact with the dashboard
- Hover over charts to see detailed data
- Map shows facility locations with equipment status
